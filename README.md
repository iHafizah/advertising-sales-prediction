# Sales Prediction with Linear & Ridge Regression

Predicting Sales from advertising spend (TV, Radio, Newspaper) and a TV×Radio interaction feature.

## What's Inside
- EDA 
- Linear Regression for predicting Sales
- Ridge Regression, compared against plain Linear Regression
- A maths intuition notebook explaining OLS, SSE, RMSE and R², tied to this project's results


## Dataset
Advertising spend data: TV, Radio and Newspaper budgets with the resulting Sales.
Source: kaggle.

## How to Run
1. Clone the repo:
   git clone https://github.com/iHafizah/advertising-sales-prediction.git
2. Install libraries:
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
3. Put advertising.csv in the same folder.
4. Open the notebooks in VS Code or Jupyter and click "Run All".

## Files
- advertising_sales_prediction.ipynb: data preparation and modeling
- maths_intuition.ipynb: the maths behind each step
- advertising.csv: dataset
